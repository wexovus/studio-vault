# Lesson format

A lesson is one reusable rule from a video, not a summary of the whole video.

- State the rule in the title.
- Say when to use it and when it fails.
- Link the source note and [[video-ingest]].
- Promote a lesson to `patterns/` only after a second source agrees with it.
